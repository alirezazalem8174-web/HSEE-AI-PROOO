# HSE AI PRO — نسخه 4.4 Final Candidate

نسخه پیش‌نهایی برای Build واقعی Android. هسته برنامه کاملاً محلی و بدون نیاز به اینترنت است.

## قابلیت‌ها
- داشبورد HSE و رابط فارسی RTL
- کتابخانه PDF، جلوگیری از تکرار و جست‌وجوی فارسی
- یادداشت روزانه
- یادآوری محلی و بازتنظیم پس از راه‌اندازی مجدد
- ارزیابی ریسک 5×5
- ثبت حادثه و شبه‌حادثه
- Backup/Restore امن و محلی

## اصل هزینه
برای قابلیت‌های اصلی هیچ API پولی، Cloud، اشتراک یا مجوز INTERNET استفاده نشده است.

## وضعیت Build
این بسته از نظر سورس و ساختار برای Build آماده شده است، اما APK در محیط فعلی تولید نشده چون Android SDK/Gradle در محیط اجرا موجود نیست. بنابراین این فایل APK نیست.
