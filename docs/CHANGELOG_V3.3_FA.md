# تغییرات نسخه ۳.۳ — بازطراحی پوسته و تجربه کاربری

- بازطراحی صفحه اصلی به شکل داشبورد HSE با هدر، وضعیت آفلاین و میانبرهای سریع.
- استفاده از کارت‌های جداگانه برای کتابخانه، یادداشت، یادآوری، ارزیابی ریسک، حادثه و پشتیبان.
- بهبود فاصله‌گذاری، خوانایی، رنگ‌بندی و سلسله‌مراتب بصری.
- پشتیبانی کامل‌تر از RTL در کنترل‌های ورودی و متن‌ها.
- نمایش وضعیت برنامه: آفلاین، رایگان و بدون API پولی.
- نمایش سطح ریسک در پیام ثبت (کم/متوسط/زیاد/بحرانی).
- اعتبارسنجی عنوان یادداشت، یادآوری و حادثه قبل از ثبت.
- اصلاح اجرای ACTION_CREATE_DOCUMENT برای پشتیبان‌گیری: فراخوانی Intent به UI thread منتقل شد.
- اصلاح رفتار Restore در خطا برای بازسازی DB و جلوگیری از باقی‌ماندن DB بسته.
- حفظ کامل معماری Offline-First و عدم افزودن INTERNET permission یا سرویس ابری.

> توجه: APK واقعی در این محیط Build نشده است؛ نسخه حاضر بسته توسعه/سورس است.
