# تغییرات HSE AI PRO v4.0

## هسته و پایداری
- ارتقای لایه دیتابیس به نسخه 6 و حفظ Migration نسخه‌های قبلی
- ایندکس‌های عملیاتی برای صفحات، منابع، یادآوری، ریسک و حادثه
- عملیات دیتابیس/فایل در Executor تک‌صفی برای کاهش هم‌زمانی خطرناک
- جست‌وجوی چندمعیاره در متن، عنوان و دسته‌بندی
- رتبه‌بندی بهتر نتایج و Snippet مقاوم‌تر در متن فارسی
- نرمال‌سازی دقیق‌تر حروف عربی/فارسی، نیم‌فاصله، اعداد، اعراب و علائم

## مدیریت اطلاعات
- فهرست منابع PDF و حذف منبع از داخل برنامه
- فهرست یادداشت‌های اخیر و حذف
- فهرست یادآوری‌ها با «انجام شد/بازکردن» و حذف
- فهرست ریسک‌های ثبت‌شده و حذف
- فهرست حوادث/شبه‌حوادث و حذف

## یادآوری
- انتخاب تاریخ و ساعت به‌جای زمان ثابت
- شناسه پایدار برای Alarm
- بازتنظیم یادآوری‌های آینده پس از Boot و بروزرسانی برنامه

## رابط کاربری
- داشبورد چهار شاخص اصلی
- دکمه‌های دسترسی سریع به بخش‌ها
- کارت‌های یکدست، راست‌چین و مناسب موبایل
- نمایش وضعیت ریسک با رنگ و امتیاز

## رایگان و آفلاین
- هیچ مجوز INTERNET اضافه نشده است.
- هیچ API پولی، سرویس ابری یا اشتراک اجباری اضافه نشده است.
